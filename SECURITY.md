# Security

Please don't report a security problem in a public issue or pull request. Contact the maintainer
privately through GitHub instead, with the steps to reproduce it and the app version
(Settings → About).

Comic Viewer reads files only from storage you grant it, opens comic archives and PDFs in place,
and sends nothing over the network apart from Google Play billing for the Pro purchase. Reports
about reading untrusted archives or PDFs, storage permissions and the purchase flow are especially
welcome.

Security fixes go into the latest version on Google Play.
